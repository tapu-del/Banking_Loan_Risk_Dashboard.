# Banking & Loan Risk Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyze loan risk data for 594K loans.

## Tools Used
- Power BI
- DAX
- Data Modeling

## What I Did
- Loaded 594K loan records
- Created 5 DAX measures (Total Loans, Total Loan Amount, Default Rate, Average Interest Rate, Avg Credit Score)
- Built dashboard with KPI cards, bar charts, pie chart, line chart
- Added slicer for Loan Purpose

## Key Insights
- Total Loans: 594K
- Total Loan Amount: 8.92 Billion
- Default Rate: 0.20
- Average Interest Rate: 12.36
- Average Credit Score: 680.92
